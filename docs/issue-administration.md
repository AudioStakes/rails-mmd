# Issue Administration

This runbook is for human issue administrators. It does not implement GitHub
automation.

## Superseding Invalid Issues

Issues `#1` through `#6` assumed the wrong repository model for `rails-mmd`.
When creating the replacement issue batch:

1. Comment on each old issue that it is superseded because it assumed the wrong
   repository model.
2. Link to the replacement issue batch.
3. Close each old issue as not planned.

Do not close GitHub issues from implementation PRs unless a later
human-approved issue explicitly asks for that administration work.
