# rails-mmd image assets

The mark depicts two connected model tables.

| Asset | Use | Dimensions | Size |
| --- | --- | --- | --- |
| [Square icon](rails-mmd-icon.png) | README headers or other project references | 1254 × 1254 | 976 KB |
| [Social preview](rails-mmd-social-preview.jpg) | Repository README and GitHub link previews | 1774 × 887 | 184 KB |

The PNG is transparent outside its rounded tile. Display the square icon at
approximately 96–128 pixels when using it in a README header.

To set the repository's social preview, upload the JPEG through
**Settings → Social preview → Edit → Upload an image**. It has a 2:1 aspect
ratio and is below GitHub's 1 MB limit. See the
[GitHub requirements](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).

The assets were created with the built-in image generation tool. The social
preview was exported as JPEG for the upload size limit.
